# competitor-change-radar

A competitor intelligence radar using Firecrawl to track changes across competitor websites.

Built using **Software Development Workspace**.

### Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rznies/competitor-change-radar.git
   ```
2. Install dependencies (if applicable):
   ```bash
   npm install
   ```
3. Run the development environment or execute scripts according to project files.
